My courses / Data Structures

Data Structures

Computer Science · 4 credits · Dr. Mehta · Room A204 · Mon, Wed 9:00

About this course

You learn how data is organised in memory and how to choose the right structure for a problem. The course covers arrays, linked lists, stacks, queues, trees, hash tables and graphs, with a focus on running time.

Prerequisite: Introduction to Programming.

Syllabus

Unit 1: Foundations (weeks 1–3)
  • Arrays and memory
  • Linked lists
  • Big-O notation
Unit 2: Trees (weeks 4–7)
  • Tree basics and traversals
  • Binary search trees
  • Heaps and priority queues
Unit 3: Graphs and hashing (weeks 8–12)
  • Graph basics, BFS and DFS
  • Hash tables
  • Shortest paths
