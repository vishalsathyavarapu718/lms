Lesson 9: Binary search trees

Video · 18 min

What is a binary search tree?

Every node follows one rule: values in its left subtree are smaller and values in its right subtree are larger. A lookup can skip half of the remaining nodes at each step.

Searching for a value

Start at the root. Go left if the target is smaller, right if it is larger, and stop when you find it or reach an empty spot.

function search(node, target) {
  if (node === null) return false;
  if (target === node.value) return true;
  return target < node.value
    ? search(node.left, target)
    : search(node.right, target);
}

Balanced trees search in O(log n). Sorted inserts can degrade this to O(n).
